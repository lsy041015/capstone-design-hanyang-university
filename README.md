# 무인 세탁물 수령 시스템 (Automated Unmanned Laundry Pickup System)

한양대학교 캡스톤디자인(Hanyang University Capstone Design) 프로젝트입니다.

> **세탁이 끝난 의류와 신발을 자동화 셀이 보관하고, 인증한 고객에게 24시간 내주는 무인 세탁 수령소 컨셉입니다.**
> V2.0은 매장 전체(고객 로비, 셀프 빨래방, 자동화 셀, 직원 공간)와 직원·고객·휠체어 사용자의 동작을 하나의 1:1 Blender 타임라인에 담았습니다.
> 로봇은 옷감이나 신발 대신 운반구의 10 mm 고정 탭만 잡고, 사람은 움직이는 기계 밖에 머뭅니다.

> **상태: V2.0 — 시각·기하·동작 설계 컨셉입니다. 제작하거나 인증받은 기계가 아닙니다.** 저장한 모델을 다시 열어 자동 검사 7개를 통과했습니다
> (인터록 6,620프레임 위반 0, 로봇 동작 1,004프레임 간섭 0 등). 시간은 가정 축 속도로 계산한 모델 시간이고, 로봇 형상은 목표 기종 FR5e가 아닌
> UR5 CB-series 대체 메시입니다. [한계와 다음 단계](#16-한계와-다음-단계)를 먼저 읽어 주세요.

## 1. 왜 만들었나

매장 직원이 직접 건네주지 않아도 고객이 세탁 완료품을 찾아가게 하려면 세 가지를 함께 풀어야 합니다.

- **맞는 물품을 맞는 사람에게.** 인증한 고객에게 그 주문의 의류나 신발만 나와야 하고, 같은 재고를 두 요청이 가져가면 안 됩니다.
- **사람은 기계 밖에.** 직원이 물품을 넣을 때도, 고객이 꺼낼 때도 움직이는 기구에 손이 닿지 않아야 합니다.
- **모양이 다른 두 물품.** 옷걸이에 거는 의류와 한 켤레씩 담는 신발을 한 셀 안에서 따로 보관하고 내줘야 합니다.

V2.0은 셀만 따로 그리지 않고 매장 하나를 통째로 설계했습니다. 고객은 로비, 직원은 뒤쪽 직원 공간, 기계는 보호된 셀 안에만 있고,
서로 만나는 곳은 양문 수령함 2개와 라이트 커튼 보충구 2개뿐입니다. 직원이 무엇을 넣고 고객이 어디에 손을 뻗는지까지 1:1 시간으로 따라가며 확인했습니다.
세탁·건조, 옷을 옷걸이에 거는 일, 검수·포장은 사람의 일로 남깁니다. 저장소에는 시장 조사나 비용 분석 자료가 없습니다.

## 2. 한눈에 보기

시연 모델의 규모입니다. 상용 매장의 용량이나 수익성을 뜻하지 않습니다.

- 매장 실내 10.5 × 7.5 m(약 79 m²), 천장 2.8 m
- 의류 캐리어 26개(C01 순환 보관), 신발 트레이 12개(C03 수직 보관기, VLM)
- 직원 의류 보충창 1곳, VLM 직원 베이 1곳, 고객 수령함 A(의류)·B(신발)
- 로봇 셀 1개: FR5e 적용 검토를 위해 공식 UR5 CB-series STL을 형상·공칭 기구학 대체물로 사용
- 1:1 마스터 타임라인 6,620프레임(220.6초, 30 fps), 세부 공정 25단계

| 기능 | 하는 일 |
|---|---|
| **직원 입고** | 의류는 보충창 RFID 스캔 → 빈 캐리어 인덱싱 → 걸기 → 완료 버튼 순서입니다. 신발은 VLM이 빈 트레이를 직원 베이로 내보내면 새들백을 올리고 완료를 누릅니다. 라이트 커튼이 손을 감지하는 동안 해당 축은 멈춥니다. |
| **보관** | 의류는 C01 수평 체인 루프(캐리어 26개, 피치 203.2 mm)에, 신발은 C03 VLM(2열 × 7단, 보관 12칸)에 둡니다. |
| **고객 인증** | 키오스크에서 QR이나 수령번호로 인증하면 주문을 확인하고 물품을 예약한 뒤 준비를 시작합니다. 화면은 목업입니다. |
| **의류 출고** | C01 인덱싱·핀 체결·RFID 재확인 → C05 로봇 탭 파지 → 28 mm 리프트오프 → 0.5 m 인출 → 90° 회전 → A 수령 핀 거치·래치 → 내부 셔터 닫힘 → Y 450 mm 이송. |
| **신발 출고** | 의류와 동시에 VLM 승강·후크 추출 → 포트 컨베이어 → 로봇 → B 롤러 컨베이어 → 내부 셔터 닫힘 순서로 진행합니다. |
| **수령** | 양문 인터록: 내부 셔터가 닫히고 잠겨야 고객문이 열립니다. 옷걸이는 1.43 m, 신발 트레이 면은 0.85 m에서 받습니다. |
| **빈 운반구 회수** | 고객은 옷걸이째 의류와 새들백만 가져갑니다. 빈 어댑터는 원래 캐리어로, 빈 트레이는 VLM 빈 칸으로 자동 복귀합니다. |
| **접근성** | 낮은 위치 모드를 고르면 걸이를 23 cm 내려 1.20 m에서 받습니다. 회전 공간 지름 1.5 m, 조작부 0.4–1.2 m. |
| **정비** | SERVICE 키 → 로봇 원점·전 축 정지 확인 → 가드 잠금 해제 → 정비문 → LOTO → 닫힘·잠금 → AUTO 키 → 리셋. 자동 재기동은 없습니다. |
| **결과물** | 세부 공정 이미지 42장(6개 공정 폴더), 2분 V2.0 티저와 한국어 자막, 공정 설계서, 검증 기록, 설계 신호·부품·제어 속성 목록(CSV). |

## 3. 동작 방식

매장은 고객 로비, 셀프 빨래방, 자동화 셀, 직원 공간으로 나뉩니다. 셀은 2.4 m 고정 가드와 메시 지붕으로 막혀 있고,
모든 전환은 위치·ID·안착·잠금 가운데 하나를 확인한 뒤에만 일어납니다.

```text
 1. 직원 입고 (라이트 커튼이 손을 감지하는 동안 해당 축 정지)
    의류: RFID 스캔 → 빈 캐리어 인덱싱 · 핀 → 보충창에 걸기 → 완료 · ID 재확인 → C01
    신발: 빈 트레이 → VLM 직원 베이 → 새들백 올리기 → 완료 → C03 빈 칸

 2. 고객 인증 (키오스크 QR 또는 수령번호)
    주문 확인 → 물품 예약 → 의류 · 신발 준비를 동시에 시작

 3. 의류 출고 (주문 → A 준비 27.5 s)
    C01 인덱싱 · 핀 · RFID → C05 탭 파지 → 28 mm 리프트오프 → 0.5 m 인출
    → 90° 회전 → C02 수령 핀 · 래치 → 내부 셔터 닫힘 → Y 450 mm → A 고객문 해제

 4. 신발 출고 (주문 → B 준비 40.1 s, 의류와 병렬)
    C03 승강 · 후크 추출 → 포트 컨베이어 → C05 → C06 롤러 → 내부 셔터 닫힘 → B 고객문 해제

 5. 수령과 회수
    옷걸이째 의류 · 새들백 수령 → 문 닫힘 · 제거 확인 → 주문 완료
    빈 어댑터 → C01 원래 캐리어, 빈 트레이 → C03 빈 칸

 6. 접근성과 정비
    낮은 위치 모드: Z 230 mm 하강 → 걸이 1.20 m
    SERVICE 키 → 로봇 원점 · 전 축 정지 → 가드 잠금 해제 → 정비 → 리셋 (자동 재기동 없음)
```

## 8. 공정 순서와 허용 조건

각 동작 뒤에는 확인이 하나씩 붙고, 확인이 실패하면 다음 동작을 막습니다. 전체 표는 [공정 설계서 5장](docs/v2.0_process_design.md#5-공정-순서와-허용-조건)에 있습니다.

| 공정 | 동작 | 다음 단계 허용 조건 |
|---|---|---|
| 직원 의류 입고 | 태그를 보충창 RFID 패드에 댐 → 빈 캐리어(H05) 인덱싱·핀 체결 → 옷걸이를 어댑터에 걺 → 완료 버튼 | 주문 ID 유효·빈 캐리어 있음 → 엔코더 위치 = 목표·핀 체결 → 커튼 차단 중 체인 구동 금지 → 캐리어 ID와 품목 ID 일치 |
| 직원 신발 입고 | 빈 트레이(T04)가 직원 베이로 → 새들백 올리고 완료 → 추출기가 S4에 저장 | 베이 비어 있음 → 커튼 차단 중 승강·추출 금지 → 슬롯 점유 센서 확인 뒤 재고 확정 |
| 인증 | QR 인증 → 주문 확인 → 수령하기 | 주문 유효·중복 작업 없음 → 물품 예약 |
| 의류 출고 | 인덱싱·핀·RFID → 탭 파지 → 리프트오프·인출 → 90° 이송 → 거치 → 래치 → 해제 → 후퇴 → 셔터 닫힘 → Y 이송 | 로봇 원점·캐리어 정지 → 그리퍼 위치 센서 → 안착 센서 → 래치 닫힘 뒤 그리퍼 개방 → 로봇이 A 밖·셔터 잠금·고객문 잠금일 때만 Y 이동 |
| 신발 출고 | 승강 → 후크 → 덱 → 2단 → 포트 → 로봇 → B 컨베이어 → 셔터 닫힘 | 포트·안쪽 끝 광전 센서, 셔터 잠금 |
| 수령 | A에서 옷걸이째, B에서 새들백을 꺼냄 | 제거 확인 + 문 닫힘 → 주문 완료 |
| 회수 | 빈 어댑터: A 잠금 → Y 복귀 → 셔터 개방 → 파지 → 래치 해제 → −90° 이송 → H01 거치. 빈 트레이: B 잠금 → 역송 → 로봇 → 포트 → 추출기 → S0 | 문 잠금 확인 뒤에만 셀 쪽 동작 |
| 정비 | SERVICE 키 → 신호탑 황색 → 로봇 원점 → 전 축 정지 → 가드 잠금 해제 → 정비문(60°) → 점검 → 닫힘·잠금 → AUTO 키 → 리셋 | 셀 안 작업 전 C04 주차단기에 개인 자물쇠(LOTO) |

## 9. 사이클 시간

모델 1:1 타임라인에서 잰 시간입니다. 가정 축 속도로 계산했으며 실측값이 아닙니다.

| 작업 | 시간 | 비고 |
|---|---:|---|
| 주문 → A 의류 준비 | 27.5 s | 인덱싱·핀 체결·RFID 약 4 s 포함 |
| 주문 → B 신발 준비 | 40.1 s | VLM은 주문 즉시 병렬 시작, 로봇은 의류 뒤 |
| 주문 → A 준비 (낮은 위치) | 28.4 s | Z 230 mm 하강 포함 |
| 빈 어댑터 회수 | 19–24 s | 로봇 대기 포함 |
| 빈 트레이 회수 | 40.1 s | VLM 저장까지 |
| 직원 의류 1벌 보충 | 약 7 s | 스캔 → 인덱싱 → 걸기 → 완료 |

축 한계 가정: 로봇 관절 90°/s·180°/s²(UR5 최대 180°/s의 절반), 직선 0.25 m/s·삽입 0.06 m/s, 체인 0.25 m/s, VLM 승강 0.5 m/s,
추출기 0.3 m/s, 수령부 Y 0.3 m/s·Z 0.1 m/s, 컨베이어 0.25 m/s.

## 10. 안전 · 정비 · 접근성

안전 개념은 설계 의도이며 적합성 평가가 아닙니다. 참고한 규격은 ISO 10218, ISO 13857, ISO 14119, ISO 14120, ISO 13856-2, IEC 60204-1이고,
이 모델로 위험성 평가나 적합성 확인을 하지 않았습니다.

## 15. 만들면서 고민한 것

- **끝단에서 반지름 방향으로 뺍니다.** 의류는 레일에 직교로 걸려 있어서 휠 끝단에서는 이웃 의류가 부채꼴로 벌어집니다. 로봇이 탭을 잡고
  28 mm 들어 올린 뒤 반지름 방향으로 0.5 m 빼면 이웃 의류의 바깥 끝을 지납니다(`images/v2.0/2_order_pickup/2-4b_liftoff_extract.jpg`).
- **어댑터와 트레이가 같은 탭을 씁니다.** 두 운반구 모두 10 mm 스테인리스 탭을 가져서 그리퍼 인서트 하나로 의류와 신발을 다룹니다.
  로봇은 천이나 신발을 직접 잡지 않습니다.
- **팔꿈치를 높게 두는 해를 고릅니다.** 초기 경로에서 로봇 팔이 A 수령함 모서리 기둥을 지나갔습니다. 역기구학에서 팔꿈치-상향 해를 우선하고
  셔터 앞 후퇴 거리를 0.16 m에서 0.40 m로 늘린 뒤, 로봇 동작 1,004프레임에서 간섭이 0이 됐습니다.
- **제어 리그 하나로 움직입니다.** 셀의 모든 축과 신호가 `V8_CTRL`의 속성이고, 드라이버 223개가 모두 단순식이라 Python 자동 실행 없이 동작합니다.
  타임라인은 이 속성만 키로 가집니다([제어 속성 목록](docs/v2.0_control_properties.csv)).
- **물품은 한 번에 한 주인만 가집니다.** 옷걸이·트레이·새들백은 캐리어, 로봇, 수령부, 사람 손 가운데 한 곳에만 붙어 있고, 31번의 인계에서 위치가
  0.78 mm 넘게 튀지 않습니다. 직원이 포장대에서 새들백을 드는 순간이 가장 큽니다.
- **보이지 않으면 단면으로 보여 줍니다.** 걸이 하강은 내부 셔터가 닫힌 뒤에 일어나 밖에서 보이지 않습니다. 기구를 옮기지 않고 A 수령함 동쪽 라이너만
  숨긴 단면 카메라로 보여 주고, 화면에 단면 표현이라고 밝혔습니다(`4-2_hanger_lowering.jpg`).
- **카메라도 사람 동선 밖에 둡니다.** 직원이 신발 베이로 걸어가다 카메라 위치를 지나가서, 영상에 약 0.5초 동안 인형 안쪽이 비치는 검은 화면이 섞였습니다.
  카메라와 사람 사이의 수평 거리를 프레임마다 계산하는 검사를 만들고, VLM 베이 카메라를 직원 경로에서 0.98 m 떨어진 곳으로 옮겨 해당 샷을 다시 렌더했습니다.
- **화면 글자도 공정과 맞춥니다.** 처음에는 키오스크 화면이 한 주문용뿐이라 휠체어 사용자에게도 앞 고객의 주문번호가 떴습니다. 두 번째 주문(231-418, 의류만,
  낮은 위치)용 화면 3장을 따로 두고, 보충창·VLM 베이·직원 단말이 실제 입고 대상(캐리어 H05, 트레이 T04, 주문 231-452)을 표시하게 고쳤습니다.

- 체인·벨트·볼스크루·브레이크·그리퍼를 하중·토크·처짐·정지 거리로 선정해야 합니다. 지금의 부품명은 분류 예시입니다.
- PLC와 독립 안전 회로(이중 채널, 정지 범주, 재기동)를 구현하고 현물로 시험해야 합니다.
- 직원 보충·고객 수령 동작을 실제 사람으로 측정하고, 휠체어 측면 도달 0.65 m를 실측해야 합니다.
- 결제, QR, 주문, 재고, 알림 서비스를 검증해야 합니다. 지금은 화면과 논리 조건만 있습니다.

그 밖의 주의점입니다.

- 시연 용량(의류 26, 신발 트레이 12)을 상용 매장의 용량이나 수익성으로 해석하면 안 됩니다.
- 1:1 시간과 영상의 2분은 측정한 사이클 타임이 아닙니다.
- 사람 모형은 동선·도달 검토용 양식화 인형입니다. 특정 인구 통계의 대표값을 검증하지 않았습니다.
- 편집 가능한 `.blend` 파일과 생성 스크립트가 없어서, 저장소만으로는 모델을 열거나 검사를 재현할 수 없습니다.

## 17. 출처와 라이선스

이 저장소에 쓰인 외부 자료와 권리 표시입니다.

- **라이선스**: 저장소 전체에 적용되는 라이선스 파일은 없습니다. 아래 UR5 고지는 UR5 메시에만 해당하며, 이 저장소의 글·이미지·영상에는 적용되지 않습니다.
- **UR5 메시**: 렌더와 영상 속 로봇은 Universal Robots의 공식 UR5 CB-series 단순화 STL 형상입니다. 출처는
  [Universal Robots ROS 2 Description](https://github.com/UniversalRobots/Universal_Robots_ROS2_Description/tree/89bbe795f38a7ab00fb66fe8831dfff79dc99edf/meshes/ur5/collision)의
  커밋 `89bbe795f38a7ab00fb66fe8831dfff79dc99edf`로 고정했고, BSD-3-Clause 고지는 [docs/UR5_LICENSE.txt](docs/UR5_LICENSE.txt)에 있습니다.
  이 프로젝트의 창작물이 아닙니다.
- **대체 로봇 주의**: 적용을 검토한 로봇은 FR5e입니다. UR5 메시는 배치와 공칭 기구학 검토를 위한 대체물이며, UR5 사양·형상을 FR5e 성능 자료로 제시하면 안 됩니다.
- **소리**: 내레이션은 Windows Microsoft Heami Desktop 한국어 합성 음성입니다. V2.0 배경음은 NumPy로 직접 합성했고 외부 음원을 쓰지 않았습니다.
