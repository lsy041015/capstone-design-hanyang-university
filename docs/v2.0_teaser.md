## 만든 방법

제작 스크립트는 저장소에 없습니다. 순서만 기록합니다.

1. 편집 목록(EDL)이 모델의 이벤트 시각에서 샷마다 마스터 구간을 계산합니다. 모델을 다시 만들면 편집도 따라갑니다.
2. 3,600프레임을 Blender 5.2.1 EEVEE(24 samples, 1920×1080)로 렌더합니다. 조감 샷에서는 천장과 상부 파사드 컬렉션을 숨깁니다.
3. 3D 주석점(걸이 높이, 라이트 커튼, 인덱스 휠 등)을 각 샷 카메라의 화면 좌표로 투영해 그래픽 위치를 정합니다.
4. 그래픽(상단 바, 장 표시, 하단 자막, 배속·단면 표시, 주석, 오프닝·엔딩 카드, 진행 막대)을 ASS 자막으로 만들어 영상에 입힙니다.
5. 내레이션과 NumPy 합성 배경음을 섞고(내레이션 구간 자동 감쇠), FFmpeg로 H.264·AAC 인코딩과 음량 정규화(−16 LUFS)를 합니다.

## 표현의 한계

- 사람은 동선·도달 검토용 양식화 인형입니다. 옷의 흔들림은 강체로 근사했습니다.
- 1:1 시간은 가정 축 속도로 계산한 값이며, 압축 샷은 표시했습니다. 측정된 처리 속도가 아닙니다.
- 로봇은 FR5e 적용 검토용 UR5 대체 형상입니다. 설계 신호·인터록은 Blender 논리 상태로만 표현했고, 실제 PLC·안전 회로·QR 서버는 없습니다.
- 시연 용량(의류 26, 신발 12)은 상용 매장 용량이나 사업성 가정이 아닙니다.
