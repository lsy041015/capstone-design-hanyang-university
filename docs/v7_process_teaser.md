## 프로젝트 컨셉

직원이 검수·포장·등록한 세탁 완료품을 보관하고, 고객 인증 후 해당 의류와 신발을 전달하는 소형 무인 수령 시스템이다. 고객이 물품을 가져간 뒤에는 빈 어댑터와 트레이를 회수한다. 시연 모델의 용량은 **의류 8슬롯·신발 트레이 4개·공용 직원 보충구 1개**다.

영상은 v7의 기구 형상을 사용한 **120초·1920×1080·30 fps·3,600프레임** 공정 설명이다. 한국어 설명 그래픽과 Microsoft Heami 합성 내레이션을 넣었다. 영문 자막과 한국어 대사는 별도 SRT로 제공하며, 필요한 언어의 파일을 재생기에서 함께 연다. 한국어 화면에 영문이 자동으로 겹치지 않도록 MP4 내부 자막 트랙은 넣지 않았다.

## 장면별 공정 설명

시간은 영상 재생 위치이며 설비의 실제 소요 시간이 아니다. C01~C07은 [프로젝트 기구 구분](../README.md#system-architecture)과 같다.

### 사람과 설비가 맡는 일

직원은 검수, 포장, 물품 등록, 보충구 적재, 이상 확인과 리셋을 담당한다. 고객은 인증 후 의류 또는 신발을 가져간다. 영상에서 물품만 움직이는 보충·수령 장면은 사람의 작업을 생략해 표현한 것이다. 자동으로 옷을 걸거나 신발을 포장하는 기능을 의미하지 않는다.

자동화 셀은 어댑터와 트레이를 통해 보관·인계·수령 위치 이송·빈 운반구 반환을 수행하도록 설계했다. 문 잠금, ID, 물품 존재, 파지 확인은 실제 센서 입력으로 구현해야 하는 허용 조건이며, 영상의 문 애니메이션만으로 실물 안전성이 검증되지는 않는다.

## 검증 범위

| 확인 항목 | 근거와 범위 |
|---|---|
| 기존 v7 원본 보존 | 원본 Blender 파일의 SHA-256을 제작 전후 비교했다. 기존 31개 검사 포즈를 덮어쓰지 않고 별도 영상 파일을 만들었다. |
| 전체 프레임 계산 | 3,600개 명령 위치의 UR5 공칭 역기구학, 의류·신발 양쪽 문의 동시 개방 금지, 직원 보충구 개방 중 로봇 정지, 트레이 파지 오프셋을 검사했다. 공칭 TCP 최대 오차는 약 0.0248 mm다. 이는 수치 계산 잔차다. |
| 저장된 애니메이션 | 새 Blender 파일을 다시 열어 351개 표본 프레임의 TCP, 카메라 전환, Y–Z 연동과 의류 문 상태를 검사했다. 저장 좌표의 최대 TCP 잔차는 약 0.0198 mm다. |
| 선택한 강체 간섭 | 위 표본 프레임에서 표시되는 의류·트레이와 선택한 받침대·프레임·레일·로봇 링크 사이의 삼각형 교차는 검출되지 않았다. 검사 대상과 표본 사이를 포함한 전체 연속 충돌 검사는 아니다. |
| 영상 파일 | 게시 파일의 해상도·프레임 수·음성·자막·챕터·전체 디코딩 결과는 [게시 파일 검증 기록](v7_video_verification.json)에 기록했다. |

공정은 발표용으로 시간 압축했고, 일부 이동은 컷 전환으로 요약했다. 120초를 설비의 사이클 타임으로 사용할 수 없다. 전체 연속 궤적, 로봇 자가 충돌, 유연한 의류 거동, 하중·파지력·정지 거리, FR5e 실제 제어, PLC·독립 안전 회로와 인증 서버는 별도 검증이 필요하다.

## 모델과 자료 출처

FR5e 적용을 검토하는 프로젝트이며, 영상에는 **공식 UR5 CB-series의 단순화된 STL 대체 형상과 공칭 기구학**을 사용했다. UR5 형상이나 사양을 FR5e 성능으로 해석하지 않는다.

- 형상 제공자: [Universal Robots ROS 2 Description](https://github.com/UniversalRobots/Universal_Robots_ROS2_Description/tree/89bbe795f38a7ab00fb66fe8831dfff79dc99edf/meshes/ur5/collision)

- 모델 라이선스: [BSD-3-Clause 고지](UR5_LICENSE.txt)
- 음성: Windows Microsoft Heami Desktop의 한국어 합성 음성. 별도 배경 음악은 사용하지 않았다.

## 버전 구분

- **v7 티저:** 현재 기구 형상, 21장면, 120초, 의류 8슬롯·트레이 4개·공용 보충구 1개.
- **v7 원본 검사 모델:** 기존 31개 정지 검사 포즈. 티저의 3,600프레임과 번호가 다르다.
- **v4 이전 영상:** 86개 세부 공정, 60초. 이전 형상과 용량을 사용하므로 현재 v7 소개 영상과 구분한다.
