# V2.0 공정 설계서 (통합 시연 모델 v8)

작성 2026-09-29 · 대상 `무인세탁소_통합시연_v8.blend`(저장소에는 없음) · 치수 단위 m(표에서는 mm 병기) · 시간 단위 s

범위는 **세탁 완료품의 입고 등록 → 자동 보관 → 고객 인증 → 출고 → 수령 → 빈 운반구 회수**다. 세탁·건조, 옷을 옷걸이에 거는 일, 검수·포장은 사람의 작업으로 남는다. 모든 수치는 설계 가정이며, 출처가 있는 항목은 출처를 적었다. 구매품 정격, 하중 계산, 안전 인증은 포함하지 않는다.

## 1. 설계 원칙

| 원칙 | 적용 |
|---|---|
| 사람과 기계 동선 분리 | 고객은 로비, 직원은 뒤쪽 직원 공간, 기계는 보호된 셀 안에만 있다. 교차점은 양문 수령함 2개와 라이트 커튼 보충구 2개뿐이다. |
| 물품이 아닌 운반구를 잡는다 | 로봇은 의류 어댑터와 신발 트레이의 **공용 10 mm 스테인리스 탭**만 잡는다. 천·신발을 직접 잡지 않는다. |
| 한 번의 동작, 하나의 검사 | 각 이동 뒤 위치·ID·안착·잠금 중 하나를 확인하고 다음 동작을 허용한다(5장). |
| 모듈 단위 정비 | C01–C06은 각자 프레임을 가진 교체 단위다. 커버는 볼트 체결, 점검창은 투명 PC다. |
| 접근성 | 조작부 0.4–1.2 m, 휠체어 회전 공간 1.5 m, 낮은 위치 수령 1.20 m. |

## 2. 매장 배치 (실내 10.5 × 7.5 m, 천장 2.8 m, 약 79 m²)

| 구역 | 범위 (x, y m) | 내용 |
|---|---|---|
| 고객 로비 | 4.2–10.5, 0–3.0 | 자동문 입구(폭 1.6), 키오스크, A 의류·B 신발 수령함, 맡기기 사물함 12칸, 대기 벤치 |
| 셀프 빨래방 | 0–4.2, 0–7.5 | 세탁기 3, 건조기 2단 ×2, 세제 자판기, 접이대, 개수대 |
| 자동화 셀 | 4.2–8.5, 3.0–5.7 | 로봇(받침대 1.0 m), C01 순환 보관, C02/C06 수령부, C03 VLM, 가드 높이 2.4 m + 메시 지붕 |
| 직원 공간 | 북측 4.2–8.5 × 5.7–7.5, 동측 8.5–10.5 × 3.0–7.5 | 검수·포장대, 보충창, VLM 베이, C04 제어반, 로봇 컨트롤러, 정비문, 후문 |

고객 동선은 입구 → 바닥 안내선 → 키오스크(1 인증) → A·B(2 수령) → 출구다. 수령함 앞 x 5.8–8.2, y 1.4–3.0은 비워 휠체어 회전 지름 1.5 m를 확보했다.

## 3. 모듈

### C01 의류 순환 보관 — 26 캐리어

| 항목 | 값 |
|---|---|
| 방식 | 수평 사이드플렉스 체인(피치 25.4 mm, 208 링크)을 알루미늄 U 트랙에 넣고, 8링크(203.2 mm)마다 캐리어를 둔다. |
| 휠 | 128포켓, 피치 지름 1,035 mm. 동쪽 휠은 구동(중공축 헬리컬-웜 감속 모터 + 브레이크 + 절대 엔코더)·인덱스, 서쪽 휠은 스크루 테이크업 텐션 |
| 경로 | 직선 1.016 m × 2 + 반원 2개, 전체 5.283 m |
| 픽업 위치 | 동쪽 휠 끝단(s = 0). 인덱스 핀이 휠 웹의 16개 부시에 체결되어 파지 중 회전을 기계적으로 막는다. RFID로 어댑터 ID 재확인 |
| 직원 보충 위치 | 북측 직선, s = 7피치(1.422 m). 라이트 커튼 보충창 뒤 0.34 m |
| 속도 (가정) | 0.25 m/s, 0.4 m/s². 반바퀴 인덱싱 약 11 s |
| 의류 외형 (허용) | 포장 폭 ≤ 500 mm, 두께 ≤ 90 mm, 걸이 아래 길이 ≤ 1.25 m. 휠 회전부 안쪽 끝 간격 16 mm 이상(검사값) |
| 모델 연동 | 캐리어 = Follow Path(호장 오차 0.0004 mm), 체인 = 지오메트리 노드 인스턴스, 휠 각 = s / R. 모두 `c01_s` 하나로 구동 |

의류는 레일에 직교(폭이 반지름 방향)로 걸린다. 끝단에서 로봇이 탭을 잡고 28 mm 들어 올린 뒤 반지름 방향으로 0.5 m 빼낸다. 이 거리는 회전부에서 부채꼴로 벌어진 이웃 의류의 바깥 끝을 지나는 값이다.

### C06 신발 수령함 B (양문)

로봇이 트레이를 24 V MDR 롤러 컨베이어(Ø50, 피치 75 mm, 14본, 폴리-V 연동) 안쪽 끝에 놓는다. 트레이는 0.65 m 이동해 수직 슬라이딩 내부 셔터를 지나 고객 수령 위치에 선다. 롤러 면은 0.85 m, 고객문은 0.48 × 0.52 m 여닫이다. 제거 확인은 하향 ToF, 위치는 반사형 광전 센서 2개로 한다. 롤러 각 = 이송 거리 / 반지름.

### C05 로봇과 그리퍼

- 로봇: FR5e 적용 대상, 형상·기구학은 **공식 UR5 CB-series STL과 공칭 관절 원점**(Universal_Robots_ROS2_Description, 고정 커밋 `89bbe79`)을 대체 사용한다. 받침대 220 × 220 mm, 기준면 1.00 m, M16 앵커 4개.
- 그리퍼: 서보 평행 그리퍼(행정 50 mm급 분류 예시). 교체식 POM 인서트에 V 리브 2줄이 있어 탭의 리브와 맞물린다. 접근 간격 30 mm(탭 좌우 ±10 mm 포착), 파지 간격 10 mm, TCP는 플랜지에서 170 mm.
- 모델: 관절 = `r_j1..6` 드라이버, 핑거 = `r_grip`. Blender 리그와 numpy 순기구학의 TCP 차이 ≤ 1.2 × 10⁻⁶ m(검증).

### C04 제어반과 셀 구조

- 제어반 800 × 550 × 2,000 mm. 마운팅판 위에서 아래로 전원부(주차단기·SPD) → 보호(MCB·RCD) → 24 V 전원·UPS·안전 접촉기 → PLC·안전 컨트롤러·I/O·스위치 → 서보 드라이브 5축 → 단자대 순서로 배치하고 덕트로 전력·신호를 나눈다. 앞쪽 정비 공간 800 mm를 바닥에 표시했다.
- 셀: 45 mm 프로파일 기둥(≤ 1.2 m 간격), 하부 0.9 m 강판 + 상부 투명 PC, 지붕 와이어 메시, 동쪽 가드 잠금 정비문(0.85 m, 바깥 여닫이), 신호탑(녹/황/적).

| 2 | 직원이 새들백을 칸막이에 걸쳐 놓고 완료 | 커튼 차단 중 승강·추출 금지 |

### 고객 인증과 출고 (주문 123-456: 의류 H01 + 신발 T01)

| 단계 | 동작 | 조건·확인 |
|---|---|---|
| 2-2 | QR 인증 → 주문 확인 → 수령하기 | 주문 유효, 중복 작업 없음 → 물품 예약 |
| 2-3 | H01을 픽업 위치로 인덱싱, 핀 체결, RFID 재확인 | 로봇 원점, 캐리어 정지 |
| 2-4 | 로봇: 접근 → 탭 파지 → 28 mm 리프트오프 → 0.5 m 인출 | 그리퍼 위치 센서(파지), 핀 체결 유지 |
| 2-5 | 90° 회전 이송 → A 수령 핀 위로 삽입 → 거치 → 래치 → 해제 → 후퇴 | 안착 센서 → 래치 닫힘 후 그리퍼 개방 |

| 2-7–2-9 | 고객이 A에서 옷걸이째, B에서 새들백을 꺼낸다 | 제거 확인 + 문 닫힘 → 주문 완료 |

### 회수

| 대상 | 순서 |
|---|---|
| 빈 어댑터 | A 잠금 → Y 복귀 → 내부 셔터 개방 → 로봇 파지 → 래치 해제 → 리프트오프 → 인출 → −90° 이송 → H01 핀에 거치 → 인덱스 해제 |

### 접근성 수령 (주문 231-418: H02)

키오스크 무릎 공간에 정면 접근 → `낮은 위치에서 받기` → QR → 출고. A에서 Y 이송 뒤 Z가 230 mm 내려 걸이가 1.20 m가 된다. 휠체어 사용자는 문에 평행하게 대고 오른손으로 손잡이(1.05 m)를 당겨 연 뒤 옆으로 손을 뻗어 옷걸이를 잡는다(측면 도달 약 0.65 m, 모형 기준 추정).

### 정비 모드

SERVICE 키 → 신호탑 황색 → 로봇 원점 → 전 축 정지 확인 → 잠금 해제 요청 → 가드 잠금 해제 → 정비문 개방(60°) → 점검 → 닫힘·잠금 → AUTO 키 → **리셋 버튼**(자동 재기동 없음) → 녹색. 셀 안 작업 전에는 C04 주차단기에 개인 자물쇠(LOTO)를 건다.

## 6. 사이클 시간 (모델 1:1, 가정 축 속도 기준)

| 작업 | 시간 | 비고 |
|---|---:|---|
| 주문 → A 의류 준비 | 27.5 s | 인덱싱·핀 체결·RFID 약 4 s 포함 |
| 주문 → B 신발 준비 | 40.1 s | VLM은 주문 즉시 병렬 시작, 로봇은 의류 뒤 |

## 10. 로봇 프로그램

- 스테이션 5곳(C01 끝단, A 인계, VLM 포트, B 안쪽 끝, 원점)을 IK로 교시했다. 자세는 **팔꿈치를 높게 두는 해**를 우선해 셀 가구 위로 팔이 지나가게 했다.
- 접근·삽입·이탈은 직선 이동(프레임마다 IK 추종, 관절 급변 12° 초과 시 중단)이고, 스테이션 사이는 동기 사다리꼴 관절 이동이다.
- 모든 로봇 동작 프레임(3 프레임 간격)에서 로봇 링크 + 그리퍼 + 들고 있는 화물(의류 전체 길이 포함)과 주변 메시의 삼각형 교차를 검사했다. 결과 0건([v2.0_verification.md](v2.0_verification.md)).
- FR5e의 실제 링크 형상·가반하중·관성·TCP 보정이 적용되면 교시점과 경로를 다시 검증해야 한다.
