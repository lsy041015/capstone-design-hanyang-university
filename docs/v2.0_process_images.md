# V2.0 세부 공정 이미지

통합 시연 모델(내부 버전 v8)의 1:1 마스터 타임라인에서 세부 공정마다 뽑은 렌더 42장입니다. 1920×1080, Blender 5.2.1 EEVEE, 64 samples. 괄호 안 시간은 마스터 타임라인 위치(모델 시간)이며 측정한 설비 사이클 타임이 아닙니다. 사람은 동선·도달 검토용 양식화 인형입니다. [README로 돌아가기](../README.md)
