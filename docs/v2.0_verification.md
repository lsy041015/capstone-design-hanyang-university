## 3. 화면 확인

- 26개 카메라 샷의 중간 프레임과 티저 15개 샷을 1080p로 렌더해 형상·가림·동작·주석 위치를 눈으로 확인했다. 그 과정에서 고친 문제: 벽 속 카메라 4대, 고객 등이 화면을 가리는 샷 3개, 셔터가 닫혀 걸이 하강이 안 보이는 샷(단면 카메라로 교체), 흰 셔츠가 흰 셔터 앞에서 식별되지 않는 문제(색 변경), 수령 물품이 1프레임부터 숨겨지던 가시성 버그, 새들백 손잡이의 도달 거리(0.75 → 0.43 m).
- V2.0 공개 전 추가 점검(2026-09-29): 카메라–사람 간격 검사(`camera_clearance.py`, 저장소에는 없음, 카메라와 사람 기준점의 수평 거리 ≥ 0.5 m)로 `CAM_STAFF_VLM`이 직원 경로 위(최소 0.02 m, 티저 4번 샷에 약 0.5초 검은 화면)에 있던 것을 찾아 (8.30, 7.25, 2.00)으로 옮겼다(경로와 0.98 m). 두 번째 주문(231-418, 의류만, 낮은 위치)용 키오스크 화면 3장을 추가하고, 보충창·VLM 베이·직원 단말 화면 표시를 공정 값(H05, T04, 231-452)에 맞췄다. 바뀐 화면이 보이는 티저 3·4번 샷을 다시 렌더했고, 나머지 샷은 재빌드 모델과 픽셀 차이 ≤ 2레벨(화면이 멀리 보이는 1·2·15번 샷은 11–15 px)임을 확인해 그대로 썼다.
- 초기 검사에서 드러나 설계를 바꾼 항목: 로봇 팔이 A 수령함 모서리 기둥을 지나가던 관절 경로(팔꿈치-상향 해 우선), 그리퍼가 내부 셔터 평면에 걸치던 후퇴 거리(0.16 → 0.40 m), 정비문이 셀 안쪽으로 열려 VLM과 겹치던 방향(바깥 여닫이), 루프 회전부 의류와 운반 의류의 간섭(피치 8링크·루프 위치 조정).
