# V2.0 기구 분해도

V2.0 통합 시연 모델(내부 버전 v8)의 모듈을 부품 그룹별로 벌려 놓고 정사영으로 렌더한 분해도 8장입니다. 번호는 이미지 속 이름표 번호와 같습니다. 분해 위치는 설명용 배치이며 실제 분해 순서가 아닙니다. 부품명은 분류 예시이고 치수는 모델 공칭값입니다. [README로 돌아가기](../README.md)
